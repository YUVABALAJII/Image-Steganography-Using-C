# Image Steganography Using C

## Project Overview

Image Steganography is a technique used to hide secret information inside an image. This project implements image-based encoding and decoding using the C programming language and BMP image files.

The application provides separate encoding and decoding operations through a command-line interface.

## Features

- Encode secret text into a BMP image.
- Decode and extract hidden information from an encoded image.
- Separate encoding and decoding modules.
- Command-line interface.
- Support for BMP image files.

## Technologies Used

- C Programming
- File Handling
- Pointers and Structures
- BMP Image Processing
- Modular Programming

## How It Works

### Encoding
The encoding module takes a BMP image and a text file as inputs and generates an encoded BMP image.

### Decoding
The decoding module extracts the hidden information from the encoded BMP image.
